目标路径规划

选一个目标，算出从当前位置到它还需要按什么顺序学

    为什么需要它

    01

    路径是图，不是清单

    一个知识点往往同时是多个知识点的前置。HTTP 与调用 API 就需要 JSON、虚拟环境、异常处理三样同时具备 —— 用线性清单表达不了这种汇聚关系。

    引擎会校验循环依赖和孤立节点。内容长到几百个节点时，手工维护必然出错。

    02

    每个节点都带真实踩坑记录

    现成的项目列表都只给你一个链接，剩下的靠悟。这里除了链接，还写清楚 必须先会哪几样、真正卡人的地方在哪、当初怎么绕过去的。

    项目列表可以复制，踩坑记录不能。

    03

    不设标准答案，双平台可用

    每个节点给一组验收标准，逐条自评，全部通过即合格。 做到什么程度算够，比追求完美更重要。

    成果可以提交到 GitHub 或 Gitee，两条路都通。
